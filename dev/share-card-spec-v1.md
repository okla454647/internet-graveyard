# Share Card v1

## Purpose
Turn every new grave into a social object that advertises Internet Graveyard by itself.

## Project card
Visual hierarchy:
1. INTERNET GRAVEYARD
2. 🪦 GRAVE #N
3. Project name
4. “epitaph” in quotation marks
5. Cause of death
6. BURIED ON INTERNET GRAVEYARD
7. short canonical URL

Suggested 1080 × 1350 portrait export for social sharing. Also support 1200 × 630 landscape later.

Copy example:
INTERNET GRAVEYARD
GRAVE #27
MY FAILED GAME
“I really thought this would work.”
CAUSE OF DEATH · Lost motivation
BURIED ON INTERNET GRAVEYARD

## Memorial card
Never use GRAVE / FAILED / CAUSE OF DEATH language.
Use:
INTERNET GRAVEYARD · MEMORIAL GARDEN
MEMORIAL #N
Name
Words left behind
REMEMBERED ON MEMORIAL GARDEN

## Interaction
Detail page action: 下載分享卡 / DOWNLOAD SHARE CARD
After creation, share card should be surfaced next to normal share.
Implementation: browser Canvas API, generated from existing grave data. No backend image generation needed.

## Future paid value
Free card: standard stone treatment.
Paid grave themes automatically change exported card treatment too, increasing visible value of upgrades.
